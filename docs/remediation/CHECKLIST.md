Contract changes introduced in Phase 1 (for the changelog / advisory):
- Tokens now carry `kid`, `iss`, `aud`; tokens issued by earlier versions are rejected (forced re-login).
- `JWT_SECRET` must be ≥ 32 random chars; `SUPERSECURESECRET` and other placeholders are rejected.
- `registerModel` moved: `@/core/register-model` → `@/plugins/db-mongoose/register-model`; conflicting schemas now throw.
- `error.cause` on Geo/Cloudinary/Payment errors is a safe summary `{ name, message, code, status }`, not the raw SDK/Axios error.
- Payment: production never uses the mock gateway; dummy Razorpay defaults removed; mock signatures are per-process HMACs (`signForTesting`).
- `PLUGINS` with unknown names or missing requirements now fails startup (previously ignored / warned).
- Optional decorators (`app.redis`, `app.cache`, `app.queue`, `app.event`, `app.geo`, …) are typed optional and only exist when the plugin is generated.
- Removed unreferenced stubs: metrics controller/service/repository/schema, `auth.repository.ts`, `db-prisma/prisma.adapter.ts`, `config/app.ts`, `bootstrap/config.ts`.
